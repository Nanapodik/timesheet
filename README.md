\# Timesheet API



REST API для учета рабочего времени сотрудников.



Проект разработан на Python с использованием FastAPI, PostgreSQL и SQLAlchemy.  

В приложении реализованы организации, сотрудники, плановое и фактическое рабочее время, фиксация месячного плана, авторизация пользователей и разграничение доступа.



\## Возможности



\- управление организациями;

\- управление сотрудниками;

\- создание планового рабочего времени;

\- фиксация месячного плана;

\- запрет изменения зафиксированного плана;

\- учет фактически отработанного времени;

\- запрет внесения факта за будущую дату;

\- проверка правила `Факт ≤ План`;

\- формирование отчетов;

\- регистрация и авторизация пользователей;

\- JWT-аутентификация;

\- роли `admin` и `user`;

\- разграничение доступа к API;

\- автоматические API-тесты;

\- интеграционный тест с PostgreSQL;

\- запуск проекта через Docker Compose;

\- миграции базы данных с Alembic.
